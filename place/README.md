# Aether v0.7 — THRESHOLD

Um limiar coletivo. Não é um feed. Não é um app de IA.
É um organismo que continua respirando quando você sai.

## Abrir

Abra `index.html` no navegador. Não precisa instalar nada.

## O que há de novo

**Abordagem** — enquanto você escreve, o campo se comprime. O organismo sente a intenção antes da contribuição.

**Dissolução** — o texto não some: vira matéria luminosa, atravessa o vazio e é absorvido.

**Estratos** — no silêncio, residuais antigos atravessam o campo como pressão, não como lista.

**Retorno** — se você esteve ausente, o campo conta as respirações que passaram sem presença.

**Respiração global** — o número não recomeça quando você entra. O campo já estava vivo.

**Ausência verdadeira** — o centro não é desenhado. O vazio existe porque as partículas se recusam a ocupá-lo.

## Ritual

1. Só o campo
2. Era + respiração
3. Narrativa
4. “O que você traz?”

## Teste

Fique 30 segundos sem tocar. Escreva. Saia. Volte.
